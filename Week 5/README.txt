WEEK 5 COMPREHENSIVE DATA SCIENCE PROJECT

Files
- Week_5_Comprehensive_Data_Science_Project_Report.docx: final written report. Charts are separate and are not embedded in the Word document.
- week5_comprehensive_analysis.py: integrated preprocessing, statistical testing, logistic regression, evaluation, and figure generation.
- week5_final_project_analysis.ipynb: cell-based notebook following the supplied Week 5 notebook example and using the Telco dataset.
- Telco-Customer-Churn.csv: dataset used by the project.
- week5_figures: selected figures from Weeks 1 to 4, plus figures generated by the Week 5 script.

Run the integrated analysis from this folder:
1. Install packages: py -m pip install -r requirements.txt
2. Run: py week5_comprehensive_analysis.py

Or open week5_final_project_analysis.ipynb in VS Code/Jupyter and run the cells from top to bottom.

The script writes week5_model_metrics.csv and four new PNG figures into week5_figures.
